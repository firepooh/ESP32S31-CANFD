ESP32-S31 CAN-FD Web Flasher

Flash the ESP32-S31-Function-CoreBoard-1 firmware (CAN-FD 2-port tester, USB-CAN adapter, OBD-II ECU simulator) straight from the browser. Use desktop Chrome or Edge.

This browser does not support Web Serial. Please open this page in desktop Chrome or Edge.

ESP-IDF flashes the ESP32-S31 without the stub (--no-stub), so this is the default. Uncheck it to use the esptool-js stub, which is faster and allows erasing the whole flash.

0%

How to use

  1. Connect the board's USB-UART (CP210x) port to the PC.
  2. Press 1. Connect and pick the board's COM port. Check that the chip is an ESP32-S31.
  3. Choose a version and press 2. Flash. The board resets automatically when done.
  4. If it does not connect, hold the Boot button, press and release Reset to enter download mode, then connect again.

Log

merged.bin is a single image with the bootloader, partition table and app, written from 0x0. The binaries are built automatically with ESP-IDF v6.1 for the GitHub releases. Source: firepooh/ESP32S31-CANFD. Flashing engine: esptool-js.
